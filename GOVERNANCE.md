# Governance

## Project Lead

[Sung-Kyu Yoo](https://github.com/skyoo2003) is the project lead and primary maintainer.

## Decision Making

KVS follows a **BDFL (Benevolent Dictator for Life)** model:

- The project lead makes final decisions on technical direction, API design, and release scope
- Community input is gathered through [GitHub Issues](https://github.com/skyoo2003/kvs/issues) and [Discussions](https://github.com/skyoo2003/kvs/discussions)
- Significant changes are proposed as issues before implementation

## Release Process

- Releases follow [Semantic Versioning](https://semver.org)
- The project lead determines release scope and timing
- Changelog is managed with [Changie](https://github.com/miniscruff/changie)
- See [the release process](https://skyoo2003.github.io/kvs/docs/release/) for the full release workflow
