# Support

## Bug Reports

If you find a bug, please open a [GitHub Issue](https://github.com/skyoo2003/kvs/issues/new?template=bug_report.md) with:

- Go version and OS
- Steps to reproduce
- Expected vs actual behavior

## Feature Requests

Have an idea? Open a [Feature Request](https://github.com/skyoo2003/kvs/issues/new?template=feature_request.md).

## Questions

- Open a new discussion in [GitHub Discussions](https://github.com/skyoo2003/kvs/discussions)
- Check existing issues and discussions first — your question may already be answered

## Security Vulnerabilities

Do not open public issues for security problems. See [SECURITY.md](SECURITY.md) for responsible disclosure.
